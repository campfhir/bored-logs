# @campfhir/bored-logs-ui

Unstyled-by-default React components for rendering and filtering logs returned by a `QueryableLogAdapter`: `LogTable` (with row primitives), `LogCard`, `LogSearchBar` (+ `LogSearchSyntaxHelp`), `LogLevelFilter`, `LogDateRangePicker`, and `PurgeLogsDialog`. Ships with a `"use client"` banner for React Server Components.

```bash
npm install @campfhir/bored-logs-ui react
# or
deno add jsr:@campfhir/bored-logs-ui
```

Peer dependencies: `react`.

Full documentation, including how the packages fit together, lives in the
[bored-logs README](https://github.com/campfhir/bored-logs#readme).
